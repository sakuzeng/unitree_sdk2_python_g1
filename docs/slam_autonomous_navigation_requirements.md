# Unitree G1 SLAM自主导航系统需求文档

## 项目概述

### 项目目标
基于 Unitree G1 机器人开发SLAM自主导航系统，利用激光雷达和视觉传感器实现实时环境感知、地图构建和自主行走功能。

### 核心价值
- 提供实时SLAM建图和定位能力
- 实现智能路径规划和自主导航
- 支持复杂环境下的避障和重定位
- 为机器人自主移动提供基础平台

## 功能性需求

### 1. SLAM系统

#### 1.1 实时建图与定位
- **需求描述**: 基于KISS-ICP实现实时SLAM功能
- **功能要求**:
    - 实时点云配准和位姿估计
    - 增量式地图构建
    - 回环检测和地图优化
    - 位姿轨迹记录和可视化
- **技术规格**:
    - 更新频率: 10Hz
    - 定位精度: ±5cm
    - 建图范围: 100m × 100m
    - 处理延迟: <100ms
- **输入**: Livox Mid-360点云数据、IMU数据
- **输出**: 机器人位姿、环境地图、轨迹信息
- **优先级**: 高
- **实现状态**: 🚧 部分实现 - KISS-ICP集成存在，但稳定性需要改进

#### 1.2 地图管理
- **需求描述**: 实现地图的保存、加载和管理功能
- **功能要求**:
    - 地图自动保存和命名
    - 多地图切换和合并
    - 地图压缩和优化
    - 地图质量评估
- **技术规格**:
    - 地图格式: PCD/PLY点云格式
    - 压缩比: >50%
    - 加载时间: <5s
    - 存储空间: <100MB/100m²
- **输入**: SLAM构建的地图数据
- **输出**: 地图文件、地图元数据
- **优先级**: 中
- **实现状态**: 📋 计划开发

#### 1.3 重定位系统
- **需求描述**: 在已知地图中实现机器人重定位
- **功能要求**:
    - 全局定位初始化
    - 丢失重定位恢复
    - 多模态定位融合
    - 定位置信度评估
- **技术规格**:
    - 重定位时间: <10s
    - 成功率: >90%
    - 精度: ±10cm
- **输入**: 当前传感器数据、先验地图
- **输出**: 全局位姿、置信度
- **优先级**: 中
- **实现状态**: 📋 计划开发

### 2. 路径规划系统

#### 2.1 全局路径规划
- **需求描述**: 基于地图信息规划从起点到终点的最优路径
- **功能要求**:
    - A*或Dijkstra路径搜索算法
    - 多种路径优化策略（最短、最安全、最快）
    - 动态重规划能力
    - 路径平滑化处理
- **技术规格**:
    - 规划时间: <2s（100m路径）
    - 路径平滑度: 连续曲率
    - 内存使用: <500MB
- **输入**: 起点位置、目标位置、环境地图
- **输出**: 全局路径、路径点序列
- **优先级**: 高
- **实现状态**: 📋 需要实现

#### 2.2 局部路径规划
- **需求描述**: 实时局部路径规划和避障
- **功能要求**:
    - DWA（Dynamic Window Approach）算法
    - 实时障碍物检测和避让
    - 速度和加速度约束
    - 路径跟踪控制
- **技术规格**:
    - 规划频率: 20Hz
    - 避障距离: ≥30cm
    - 响应时间: <50ms
    - 最大速度: 1.5m/s
- **输入**: 全局路径、实时传感器数据、机器人状态
- **输出**: 局部路径、速度命令
- **优先级**: 高
- **实现状态**: 📋 需要实现

#### 2.3 行为规划
- **需求描述**: 高层次的行为决策和任务规划
- **功能要求**:
    - 任务序列分解
    - 行为状态机管理
    - 异常情况处理
    - 人机交互响应
- **输入**: 任务指令、环境状态、系统状态
- **输出**: 行为指令、状态切换
- **优先级**: 中
- **实现状态**: 📋 计划开发

### 3. 运动控制系统

#### 3.1 底层运动控制
- **需求描述**: 基于unitree_sdk2_python实现机器人运动控制
- **功能要求**:
    - 速度控制模式（线速度、角速度）
    - 位置控制模式（目标点导航）
    - 姿态控制和稳定性保持
    - 运动平滑化和加减速控制
- **技术规格**:
    - 控制频率: 50Hz
    - 速度范围: 0-1.5m/s（线速度），0-1.0rad/s（角速度）
    - 位置精度: ±5cm
    - 姿态精度: ±2°
- **输入**: 路径规划指令、传感器反馈
- **输出**: 电机控制命令、运动状态
- **优先级**: 高
- **实现状态**: 🚧 基础实现 - sport_mode控制存在，需要集成导航功能

#### 3.2 安全控制
- **需求描述**: 确保机器人安全运行的控制机制
- **功能要求**:
    - 紧急停止和安全制动
    - 碰撞检测和响应
    - 坡度和地形适应
    - 失控检测和恢复
- **技术规格**:
    - 紧急停止时间: <0.5s
    - 碰撞检测距离: ≥20cm
    - 最大坡度: 15°
    - 反应时间: <100ms
- **输入**: 安全传感器、IMU数据、碰撞信号
- **输出**: 安全状态、保护动作
- **优先级**: 高
- **实现状态**: 🚧 基础框架 - 需要完善安全逻辑

#### 3.3 自适应控制
- **需求描述**: 根据环境和任务自适应调整控制参数
- **功能要求**:
    - 地形自适应步态调整
    - 负载自适应控制
    - 环境光线自适应
    - 学习和优化能力
- **输入**: 环境参数、任务类型、历史数据
- **输出**: 优化控制参数
- **优先级**: 低
- **实现状态**: 📋 计划开发

### 配置示例
```python
# SLAM配置
SLAM_CONFIG = {
    "max_range": 30.0,          # 最大感知距离
    "min_range": 0.5,           # 最小感知距离
    "voxel_size": 0.1,          # 体素大小
    "max_points_per_voxel": 20, # 每体素最大点数
    "adaptive_threshold": True,  # 自适应阈值
}

# 路径规划配置
PLANNING_CONFIG = {
    "max_vel_x": 1.5,           # 最大线速度
    "max_vel_theta": 1.0,       # 最大角速度
    "min_obstacle_dist": 0.3,   # 最小障碍物距离
    "path_resolution": 0.05,    # 路径分辨率
    "goal_tolerance": 0.1,      # 目标容忍度
}

# 控制配置
CONTROL_CONFIG = {
    "control_frequency": 50,     # 控制频率
    "position_tolerance": 0.05,  # 位置容忍度
    "angular_tolerance": 0.05,   # 角度容忍度
    "max_acceleration": 1.0,     # 最大加速度
}
```
