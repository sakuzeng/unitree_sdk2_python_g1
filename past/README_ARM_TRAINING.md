# 手臂模型训练系统 (智能语音版)

本系统提供完整的 G1 机器人手臂运动数据收集、模型训练和推理功能，集成智能语音提示。

## 快速开始

1. **智能语音数据收集**: 
```bash
python3 arm_training_recorder.py eth0 left 60
```

2. **模型训练和部署**:
```bash
./create_arm_model.sh eth0 left 60
```

3. **启动主GUI**:
```bash
python3 run_g1_gui.py eth0
# 现在可以使用方向键进行智能控制
```

## 数据收集 (arm_training_recorder.py)

收集手臂运动的训练数据，为机器学习模型提供样本。集成语音提示系统，支持中文方向提示。

### 使用方法

```bash
# 基本用法 - 智能语音自动采集
python3 arm_training_recorder.py <网络接口> <手臂> [样本数]

# 示例: 收集60个样本，使用语音提示
python3 arm_training_recorder.py eth0 left 60

# 手动模式 (传统方式)
python3 arm_training_recorder.py eth0 left
```

### 功能特性

- **🎙️ 智能语音提示**: 使用中文语音提示方向 (上下左右前后)
- **🔄 随机序列采集**: 自动生成随机采集序列，确保数据均衡
- **📊 实时统计**: 显示每个方向的已收集样本数量
- **⏱️ 定时采集**: 语音提示后自动等待用户完成动作
- **📂 断点续传**: 从已有数据文件中读取进度，支持增量采集

### 语音系统说明

系统集成了 G1 机器人的音频客户端，通过 TTS 功能提供中文语音提示：

- **前** (qian): 向前移动手臂
- **后** (hou): 向后移动手臂  
- **左** (zuo): 向左移动手臂
- **右** (you): 向右移动手臂
- **上** (shang): 向上移动手臂
- **下** (xia): 向下移动手臂

### 采集流程

1. 程序启动后连接机器人
2. 语音播放方向提示 (如 "请向前移动手臂")
3. 等待用户手动移动机器人手臂到目标位置
4. 自动记录起始位置和结束位置
5. 重复直到收集足够样本

### 数据格式

训练数据保存为 CSV 格式，包含以下字段：
- waist_yaw: 腰部旋转角度
- direction: 移动方向 (前后左右上下)
- 左手关节角度: left_arm_[0-6]_start/end
- 右手关节角度: right_arm_[0-6]_start/end

### 控制说明

**手动模式** (传统方式):
- w: 前 / s: 后
- a: 左 / d: 右  
- q: 上 / e: 下
- Enter: 记录当前位置

**自动模式** (智能语音):
- 语音提示后等待5秒
- 用户手动移动机器人手臂
- 自动记录并进入下一个方向

### 故障排除

#### 语音问题
- **语音无法播放**: 检查音响设备连接，确保 G1 音频服务正常
- **语音延迟**: 网络延迟可能影响语音播放，等待语音完成后再操作
- **语音失败**: 程序会自动回退到文字提示模式

#### 数据收集问题
- **网络连接错误**: 检查网络接口参数 (如 eth0)
- **数据丢失**: 程序会自动保存到 CSV 文件，支持断点续传
- **关节角度异常**: 确保机器人在安全范围内移动，避免过度旋转

#### 性能优化
- **采集速度**: 自动模式可显著提高采集效率
- **数据质量**: 确保每个方向移动幅度适中，避免极端位置
- **样本平衡**: 程序自动确保每个方向样本数量均衡

## 模型训练 (train_arm_model.py)

基于收集的数据训练机器学习模型，预测手臂运动轨迹。

### 使用方法

```bash
python3 train_arm_model.py <手臂类型>

# 示例
python3 train_arm_model.py left
```

### 功能特性

- **数据预处理**: 自动清理和标准化训练数据
- **模型选择**: 使用优化的 MLPRegressor 神经网络
- **性能评估**: 提供 R² 分数和预测精度指标
- **模型保存**: 自动保存训练好的模型和元数据

### 训练过程

1. 加载 CSV 训练数据
2. 数据清洗和特征工程
3. 训练-测试集分割
4. 模型训练和优化
5. 性能评估和验证
6. 保存模型文件

## 自动化脚本 (create_arm_model.sh)

一键完成完整的模型训练工作流程，从数据收集到模型部署。

### 使用方法

```bash
./create_arm_model.sh <网络接口> <手臂> [样本数]

# 示例: 收集60个样本并训练模型
./create_arm_model.sh eth0 left 60
```

### 工作流程

1. **检查现有数据**: 统计已收集的样本数量
2. **智能数据收集**: 如果样本不足，启动语音收集器
3. **数据验证**: 检查数据质量和样本平衡性
4. **模型训练**: 自动训练并优化模型
5. **模型部署**: 生成推理接口，集成到 GUI

### 质量控制

- 自动检查样本数量 (建议60+)
- 验证每个方向的样本分布
- 模型性能评估 (R² > 0.7)
- 异常检测和数据清洗

## GUI 集成 (data/inference_arm.py)

为主 GUI 提供模型推理接口，实现智能方向键控制。

### 功能说明

- **load_bundle()**: 加载训练好的模型和元数据
- **predict_end_positions()**: 根据当前状态预测目标位置
- **方向键映射**: 将键盘输入转换为手臂运动

### GUI 使用

在主 GUI 中，训练好的模型将自动启用：

1. 按下方向键 (上下左右前后)
2. 系统根据当前手臂状态和腰部角度预测目标位置
3. 机器人智能移动到预测位置

    ↓           ↓          ↓

## 最佳实践

### 数据收集建议

1. **样本数量**: 每个方向至少10个样本，总计60-120个
2. **动作幅度**: 适中的移动距离，避免极端位置
3. **环境条件**: 在相同的工作环境下收集数据
4. **腰部角度**: 在不同腰部旋转角度下收集样本

### 模型优化

1. **数据平衡**: 确保每个方向样本数量相近
2. **特征选择**: 包含腰部角度以提高预测精度
3. **模型评估**: R² 分数应 > 0.7，否则需要更多数据
4. **定期重训**: 根据使用效果定期重新训练模型

### 故障诊断

#### 数据问题
- **样本不足**: 增加数据收集次数
- **数据质量差**: 检查机器人连接和传感器
- **方向分布不均**: 使用自动模式确保平衡采集

#### 模型问题
- **预测精度低**: 增加训练样本或检查数据质量
- **GUI 不响应**: 检查模型文件是否正确生成
- **动作异常**: 验证模型训练数据的合理性

#### 系统问题
- **语音失败**: 检查音频设备和网络连接
- **文件权限**: 确保脚本有执行权限 (`chmod +x create_arm_model.sh`)
- **依赖缺失**: 安装必要的 Python 包 (`pip install -r requirements.txt`)
